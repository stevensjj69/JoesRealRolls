# Joe's Real Rolls Foundry Module v1.5.1

Released July 24, 2026.

## Changes

- Roll replay images now expire one minute after they are received.
- Expired replay controls are restored correctly after Foundry reloads.
- Added permanent manifest and download locations for Foundry package distribution.

## Compatibility

- Minimum Foundry VTT version: 13
- Verified Foundry VTT version: 14
- Maximum Foundry VTT version: 14

## Installation note

Enable the module in each Foundry World, then set **Settings → Game Settings →
Core → Dice → Default Method** to **Joe's Real Rolls**.
